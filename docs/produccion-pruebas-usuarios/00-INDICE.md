# Pruebas de centro de producción (usuarios)

Tutoriales no técnicos para validar en piso cada mejora.

## Antes de empezar

1. Reiniciar backend y recargar el front (Ctrl+F5).
2. Elegir un día de prueba (hoy o mañana).
3. Tener a mano: una **OP normal**, una **OPL** (venta en línea), una mesa, y stock en bodega PT si van a probar envíos.

## Orden sugerido del día de prueba

1. A → B → C (producción / mesas)
2. D (materiales)
3. E (producto terminado y envíos)
4. F (usabilidad)
5. G (cierre con checklist)
