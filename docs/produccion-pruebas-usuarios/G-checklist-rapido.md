# Agente G — Checklist rápido del día (15–20 min)

Usar este cierre con el mismo día / productos de prueba. Marcar sí/no.

## Datos de la prueba

- Fecha: _______________
- Probó: _______________
- OP de prueba: _______________
- OPL de prueba: _______________
- Producto: _______________

## Checklist

| # | Prueba | OK (sí/no) | Notas |
|---|--------|------------|-------|
| 1 | Meter OPL en mesa casi llena → no bloquea por cupo | | |
| 2 | Boleta ~90 min → se ve en horas (`1h 30m`) | | |
| 3 | Fin estimado que cruza 1–2 pm → salta almuerzo | | |
| 4 | Descargar hoja del día con OP sin mesa + OPL → ambas aparecen | | |
| 5 | Entregar materiales 2 veces → solo baja MP una vez | | |
| 6 | Recibo en bodega PT → stock sube | | |
| 7 | Envío OP → stock baja exacto | | |
| 8 | Despacho OPL producida → stock baja exacto | | |
| 9 | Filtros Hoy / OPL / búsqueda → encuentran sin listado loco | | |

## Criterio de cierre

Si **1 a 8** pasan con usuarios de:

- organización / mesas
- materiales
- bodega PT

…el paquete está listo para uso diario.

## Si algo falla

Anotar:

1. Pantalla
2. OP / OPL
3. Qué esperaban
4. Qué pasó
5. Captura si pueden

Y reportarlo con el número de la fila del checklist (#1–#9).
