# Bodega PT — recepción más fácil (UX)

## Qué cambió

La pantalla **Bodega de producto terminado → Recepción** ahora está pensada para quien recibe muchas OP / OPL:

1. **Búsqueda grande** por código OP/OPL, producto, cliente o envío.
2. **Atajos:** Pendientes de recibir · Solo OPL · De hoy · Todas visibles.
3. **Tarjetas resumen:** cuántas órdenes faltan, cuántas piezas, cuántas OPL.
4. **Lista paginada** (20 + “Cargar más”) para no ahogarse.
5. Solo **una OP abierta** a la vez (clic para recibir).
6. Dentro de la OP: filtro de piezas (pendientes / recibidas) y búsqueda por producto.

## Cómo probarlo

1. Ir a **Bodega de producto terminado**.
2. Pestaña **Recepción** (debe mostrar un número amarillo si hay pendientes).
3. Dejar **Pendientes de recibir** y buscar una OPL o un código de producto.
4. Abrir la tarjeta → ver solo piezas pendientes → **Recibir todas pendientes**.
5. Si hay muchas OP, usar **Cargar más**.

## Resultado esperado

- Encuentran la OP en segundos sin recorrer un listado eterno.
- Ven claro cuántas piezas faltan.
- Al abrir, no se mezclan cientos de piezas ya recibidas (salvo que elijan “Todas”).
