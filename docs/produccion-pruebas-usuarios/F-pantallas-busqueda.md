# Agente F — Pantallas más fáciles de buscar y filtrar

## Qué cambió (en simple)

Se mejoró la usabilidad para no perderse en listados gigantes:

### Centro de producción
- Atajos: **Hoy / Atrasadas / OPL / Sin mesa**
- Búsqueda más visible

### Órdenes de producción
- Presets: **Activas · En producción · Bodega PT · Listas · OPL · Cinchos**
- La tabla empieza mostrando un bloque (ej. 50) y luego **Cargar más**

### Organizador
- Búsqueda primero / más grande
- Listas que no tiran todo de golpe (**Cargar más**)

## Quién debe probar

- Todos los usuarios de producción (organización, mesas, supervisión)

## Cómo probarlo

### Centro de producción

1. Entrar a **Centro de producción** / estación de tareas.
2. Probar los atajos:
   - **Hoy**
   - **Atrasadas**
   - **OPL**
   - **Sin mesa**
3. Usar la búsqueda con un código de OP conocido.

**Pregunta al usuario:** ¿encontraste más rápido lo de hoy / las OPL?

**Esperado:** sí, sin recorrer todo a mano.

### Órdenes de producción

1. Entrar a **Órdenes de producción**.
2. Usar el preset **OPL** (u otro).
3. Buscar un código.
4. Si hay muchas filas, usar **Cargar más**.

**Esperado:** no se ahogan con una tabla infinita de golpe.

### Organizador

1. Entrar al **Organizador**.
2. Buscar una OP por código.
3. Si la lista es larga, usar **Cargar más**.

**Esperado:** búsqueda clara y lista manejable.

## Resultado incorrecto (reportar)

- No se ven los atajos / presets.
- La búsqueda no encuentra OPs que sí existen.
- Sigue cargando cientos de filas sin opción de “cargar más”.
